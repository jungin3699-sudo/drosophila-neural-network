532026-09-19 초파리 인공 신경망 회로 히스토리+

연구 목적과 방향
- 목적: 수컷 초파리(Male CNS) 기반의 축소 신경 회로에 특정 자극을 주었을 때 미로에서 유의미한 탐색 행동이 나타나는지 살피고, 그 탐색 과정을 일반 AI 알고리즘과 비교한다.
- 방향: Male CNS 전체를 그대로 사용하지 않고, 자극 관련 입력에서 운동 관련 출력까지 이어지는 일부 회로를 추출하여 계산 모델로 구현한다. 각 뉴런은 노드, 뉴런 사이의 연결은 신호 전달 경로로 다룬다.
- 미로의 행동 출력(전진·좌회전·우회전 등)은 생물학적 연결 자체가 아니라 후속 시뮬레이션을 위한 모델링 층으로 구분하기로 하였다.

1단계 | Male CNS 및 Dimorphism 기반 탐색
- Male CNS Cell Type Explorer를 이용하여 수컷 초파리의 중추신경계 연결 정보를 탐색하였다.
- 암컷 자극/성적 행동과 관련된 후보 회로를 찾기 위해 Dimorphism을 기준으로 뉴런을 탐색하였다.
- 이 단계에서는 각 뉴런이 시각·후각 등 어떤 감각 입력과 직접 연결되는지 확정하지 않고, 우선 뉴런 사이의 연결 관계를 파악하기로 하였다.

2단계 | 초기 분기 회로 구상
- 상위 흐름으로 SMP598 → SMP702m → pC1x_a를 정리하였다.
- pC1x_a에서 oviIN, SMP052, SMP051, SMP286, SMP053으로 분기되는 구조를 확인·구상하였다.
- 그중 SMP052는 VES092, VES053, SMP593, SMP543으로 다시 분기되는 구조로 정리하였다.

초기 회로 개요
SMP598 → SMP702m → pC1x_a
                         ├→ oviIN
                         ├→ SMP052 → VES092 / VES053 / SMP593 / SMP543
                         ├→ SMP051
                         ├→ SMP286
                         └→ SMP053

3단계 | 데이터 접근 방식 결정
- 전체 뉴런/연결 파일은 별도로 다운로드하지 않기로 하였다.
- 대신 neuPrint API와 neuprint-python을 사용하여 필요한 뉴런과 연결만 조회하는 방향으로 정하였다.
- VS Code 프로젝트의 가상환경(.venv)에 neuprint-python을 설치하였다. 전체 connectome 파일을 내려받아 사용했는지 여부는 대화에서 확인되지 않음.

4단계 | VS Code에서 1차 구현 시작
- VS Code 프로젝트 폴더에 Python 파일(main.py 또는 mine.py로 언급됨)을 만들고, .venv가 아닌 프로젝트 폴더에 코드를 작성하였다.
- 먼저 SMP598 → SMP702m, SMP702m → pC1x_a, pC1x_a → SMP052의 연결 가중치를 전체 출력값으로 나누어 정규화하는 1차 코드를 구성하였다.
- 실행 결과로 위 세 연결의 정규화 값이 출력되는 것을 확인하였다.
- 초기에는 SMP052에서 DNa02/DNa15로 바로 연결할 가능성을 검토했으나, SMP052 출력표에서 두 뉴런의 직접 연결이 확인되지 않아 해당 가정은 유지하지 않기로 하였다.

5단계 | 실제 연결을 따라 회로 수정·확장
- SMP052 이후에는 VES053을 거쳐 DNa 계열로 이어지는 경로를 조사하였다.
- VES053의 출력에서 DNa11 연결이 가장 큰 후보로 확인되어, 구현 후보 경로를 SMP052 → VES053 → DNa11로 수정하였다.
- 이어 DNa11의 하위 출력에서 Sternal adductor MN을 후보로 추적하고, Sternotrochanter MN 및 Tr flexor MN 등 하위 운동 회로의 분기 가능성을 조사하였다.
- 다만 이 운동뉴런 연결을 곧바로 특정 미로 행동(전진·좌회전·우회전)으로 해석하지 않기로 하였다. 정확한 행동 대응은 대화에서 확인되지 않음.

6단계 | 오늘의 1차 최종 회로 정리
- 오늘 대화에서는 다음 두 수준의 회로가 함께 ‘1차 최종 회로’로 정리되었다.

  (가) 탐색·분기 구조
  SMP598 → SMP702m → pC1x_a → [oviIN, SMP052, SMP051, SMP286, SMP053]
  SMP052 → [VES092, VES053, SMP593, SMP543]

  (나) 실제 연결을 따라 구현 대상으로 좁힌 핵심 경로
  SMP598 → SMP702m → pC1x_a → SMP052 → VES053 → DNa11
  → Sternal adductor MN → Sternotrochanter MN → Tr flexor MN

- 따라서 오늘의 성과는 (1) pC1x_a를 중심으로 한 전체 분기 구조를 정리하고, (2) 그중 VES053과 DNa11을 경유하는 운동 회로 후보를 추적하며, (3) VS Code에서 상위 연결 가중치 계산을 실행해 본 것이다.
- 1차 최종 회로의 모든 연결을 하나의 완성된 프로그램으로 통합하여 실행했는지 여부는 대화에서 확인되지 않음.

후속 과제
- 각 뉴런의 감각 입력 및 기능을 추가 확인한다.
- 핵심 경로의 실제 연결값을 바탕으로 계산 모델을 확장한다.
- 운동 회로 출력을 미로 행동으로 변환하는 규칙/확률 모델을 별도 가정으로 설계한다.
- 동일한 미로에서 Male CNS 기반 모델과 Random, BFS, A* 등 비교 모델을 실험한다.
